# 🎮 Tic-Tac-Toe P2P (Serverless)

![PeerJS](https://img.shields.io/badge/PeerJS-WebRTC-green) ![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue)

Полностью серверлесс версия игры Крестики-Нолики. Работает прямо в браузере через прямую связь (P2P).

## 🌍 Как играть (GitHub Pages)

### 1. Откройте сайт
https://kerimbekavatar-eng.github.io/krm

### 2. Создать комнату
- Нажмите **"Создать комнату"**.
- Скопируйте 4-значный код (например `A1B2`).
- Отправьте код другу.

### 3. Присоединиться
- Друг открывает **ту же ссылку**.
- Вводит код комнаты.
- Нажимает **"Войти"**.

---

## 🛠 Как это работает?
Вместо центрального сервера игра использует технологию **WebRTC (через PeerJS)**.
Ваш браузер соединяется напрямую с браузером друга.

- **Hosting**: GitHub Pages (статика)
- **Signaling**: PeerJS Cloud (бесплатный брокер соединений)
